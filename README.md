# Rock Paper Scissors

A simple Rock Paper Scissors game built using **HTML, CSS, and JavaScript**.

## 🎮 Live Demo

[Play the Game](https://palakchaudhar-y.github.io/rock-paper-scissors/)

## ✨ Features

- Rock, Paper, and Scissors choices
- Computer generates a random choice
- Displays Win, Lose, or Draw
- Keeps track of User and Computer scores
- Interactive buttons and messages

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript
